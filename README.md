# Proyecto Logia Teófilo Leal N° 115

Landing institucional y sistema básico de gestión de aspirantes para la Respetable Logia Teófilo Leal N° 115.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- Node.js
- Express
- JSON como almacenamiento temporal

## Funcionalidades

- Landing institucional
- Página de aspirantes
- Formulario conectado al backend
- Login administrativo
- Panel de aspirantes
- Cambio de estado de aspirantes
- Eliminación de registros
- Página de reseña histórica de Teófilo Leal

## Ejecutar el proyecto

En PowerShell, dentro de la carpeta del proyecto, ejecutar:

npm install
node backend/server.js

Luego abrir el navegador y entrar a:

http://localhost:3000
